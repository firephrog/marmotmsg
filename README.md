Most of you people are probably here just to download the latest version of Marmot, and do not care about any of the code. If you wish to do that, go to https://github.com/firephrog/marmotmsg/releases and download the HTML file of the latest one. 

Or, you can choose to use the Github Pages site, which is at firephrog.github.io/marmotmsg


# Marmot

A browser messaging app that uses the Signal protocol. Includes several features, such as group chats, profile customization, voice chats, and a Discord channel linking system.

Discord servers that install the Marmot discord bot can link specific channels to Marmot, so that the users on both platforms can chat with eachother.

The entire app is designed to be loadable from a single html file, featuring an auto updater. The benefit to using a raw HTML file is that it makes Marmot easily servable and loadable. If you don't want to use this, there is a hosted one up at https://firephrog.github.io/marmotmsg

The entire thing remains open source if you either have trust issues, want to host Marmot yourself, or if you just want to flip through the code.
